# OhFOME

Demonstração web de uma plataforma de turismo gastronômico que conecta turistas e moradores aos pequenos estabelecimentos de alimentação de Teresina (PI).

## Demonstração

[Acessar a versão publicada na Vercel](https://ohfome.vercel.app)

## O que o protótipo apresenta

- busca por comida, orçamento e preferência;
- filtros rápidos e ordenação por proximidade;
- perfis demonstrativos de pequenos negócios;
- favoritos salvos durante a navegação;
- jornada do usuário em quatro passos;
- fluxo de desenvolvimento do produto em cinco etapas;
- proposta de valor para comerciantes locais.

## Desenvolvimento local

```bash
npm install
npm run dev
```

Depois, acesse `http://localhost:3000`.

## Observação

Os nomes, preços, avaliações e distâncias mostrados são dados fictícios usados apenas para demonstrar a experiência.
